## API

Интерактивная документация (SwaggerUI): https://raw.githack.com/pgeth/tamagotchi2000/apispec/swagger.html

Страница загружает [спецификацию OpenAPI](openapi.yaml) из той же ветки.
Внешняя библиотека SwaggerUI требует согласования с преподавателем.
Публичная страница предназначена для просмотра контракта: вызовы локального API через
`Try it out` зависят от запущенного сервера и CORS/политик браузера; их работоспособность не подтверждена.

Сервер принимает и отдаёт JSON. Адрес: `http://localhost:8008`.

Запуск существующего Python-сервера из корня репозитория:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m flask --app tegugotchi.backend.server.app:create_app run --host 127.0.0.1 --port 8008
```

Команда `python main.py` пока не запускает сервер: точка входа остаётся заготовкой.
Данные текущего HTTP-сервера хранятся в памяти и теряются при перезапуске;
наличие отдельного модуля БД ещё не означает, что API использует MongoDB.

Питомец — единственный ресурс сервера. Действия с питомцем (покормить, погладить и т.д.) выполняются запросами `POST /pets/{pet_id}/{action}`.

### Таблица эндпоинтов

| Название действия | Локейшн (URL) | Тип запроса | Описание запроса и ответа |
|---|---|---|---|

| Погладить | `/pets/{pet_id}/pat` | POST | Запрос: `pet_id` в пути, тела нет. Счастье +1, голод +1. Ответ `200`: обновлённая статистика или сообщение об исчезновении. Ошибка `404`: питомца нет или он исчез. |

| Погулять | `/pets/{pet_id}/walk` | POST | Запрос: `pet_id` в пути, тела нет. Счастье +1, голод +3. Ответ `200`: обновлённая статистика или сообщение об исчезновении. Ошибка `404`: питомца нет или он исчез. |

### Подробное описание

#### Создать питомца: `POST /pets`

Тело запроса — JSON-объект:

```json
{"name": "Жма", "hp": 10}
```

- `name` — непустая строка (из одних пробелов нельзя);
- `hp` — целое число больше 0 (строка, дробное число и `true`/`false` не подходят).

Ответ `201 Created`. Идентификатор `id` выдаёт сервер (1, 2, 3, ...), счастье и голод при создании всегда равны 2:

```json
{"id": 1, "name": "Жма", "hp": 10, "happiness": 2, "hunger": 2}
```

Ошибка `400 Bad Request` — тело не является JSON-объектом, `name` не строка или пустая, `hp` не целое или не больше 0:

```json
{"error": "name must be a non-empty string"}
```

#### Получить статистику: `GET /pets/{pet_id}`

Параметр пути `pet_id` — целое число.

Ответ `200 OK`:

```json
{"id": 1, "name": "Жма", "hp": 10, "happiness": 2, "hunger": 2}
```

Ошибка `404 Not Found` — такого питомца нет или он уже исчез:

```json
{"error": "pet not found"}
```

#### Действия с питомцем: `POST /pets/{pet_id}/{action}`

Параметры пути:

- `pet_id` — целое число;
- `action` — одно из `feed`, `pat`, `treat`, `walk`, `ignore`.

Тела у запроса нет.

Ответ `200 OK` — обновлённая статистика питомца (пример для `pat` на только что созданном питомце):

```json
{"id": 1, "name": "Жма", "hp": 10, "happiness": 3, "hunger": 3}
```

Если после действия питомец исчез, ответ тоже `200 OK`, но с другим телом:

```json
{"id": 1, "gone": true, "message": "Жма исчез"}
```

Ошибки:

- `404 Not Found` — неизвестный `pet_id` или неизвестное действие: `{"error": "pet not found"}`;
- `405 Method Not Allowed` — неподдерживаемый метод (например, GET): `{"error": "method not allowed"}`.

Любой неизвестный адрес возвращает `404 Not Found`: `{"error": "not found"}`.
Нечисловой или отрицательный `pet_id` не соответствует маршруту и тоже даёт `not found`.
Для числового ID, которого нет в хранилище, ответ — `pet not found`.
Неподдерживаемые методы на существующих маршрутах возвращают `405` с `method not allowed`.
Flask автоматически обрабатывает `OPTIONS`, а для GET-маршрута — также `HEAD` (без тела ответа).

### Действия и изменение показателей

| Действие | URL-суффикс | Счастье | Голод |
|---|---|---|---|
| Покормить | `feed` | — | −2 |
| Погладить | `pat` | +1 | +1 |
| Дать вкусняшку | `treat` | +2 | −1 |
| Погулять | `walk` | +1 | +3 |
| Игнорировать | `ignore` | −1 | +1 |

### Правила игры

- Начальные значения: счастье 2, голод 2.
- Голод не опускается ниже 0.
- Если после действия голод больше 5, питомец теряет 1 hp. Штрафы за подряд идущие такие действия растут: −1, −2, −3 и так далее. Если следующее действие штрафа не вызвало, счётчик сбрасывается.
- Если hp становится 0 или меньше, либо счастье становится 0 или меньше, питомец исчезает и удаляется. Дальнейшие запросы к нему возвращают `404`.
