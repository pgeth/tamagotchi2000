# Структура проекта (Project Structure)

Проект **Tegugotchi** — виртуальный питомец с REST API, хранением данных в MongoDB и автотестами.

## Дерево папок и файлов

```
├── conf                        - Конфиги
├── docs                        - Документация
│	├── MAIN_TASK.md
│	└── PROJECT_STRUCTURE.md
├── main.py                     - Входная точка проекта
├── README.md
├── tegugotchi                  - Главный модуль проекта
│	├── backend                 - Подмодуль ответственный за реализацию серверной логики
│	│	├── database            - Подмодуль ответственный за базу данных
│	│	├── pet.py              - Подмодуль ответственный за реализацию объектов
│	│	└── server              - Подмодуль ответственный за клиент-серверное взаимодействие
│	└── frontend                - Подмодуль ответственный за фронтенд
└── tests                       - Тесты
```
